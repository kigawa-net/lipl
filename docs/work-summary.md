# 作品概要書（あいちセレクト AIコンテスト2026 提出用）

- **提出先**: [あいちセレクト AIコンテスト](https://aichi-select.net/ai_contest/)
- **参加部門**: クリエイティブ部門（1名エントリー）
- **企画名**: Lipl（リプル）
- **キャッチコピー**: お店の情報を入力するだけ。3分で公式ページを公開。

> 本書は [docs/ai-app-proposal.md](ai-app-proposal.md) の企画案をもとに、提出用の作品概要書としてまとめたもの。

## 1. 解決したい課題

個人経営の飲食店（カフェ・居酒屋・ラーメン店・キッチンカーなど）の多くは、公式ページを持たずSNS（Instagramなど）のみで営業案内をしている。

- HTML/CSS・サーバー・ドメイン・DNSの知識がなく、自前で公式ページを作れない
- 制作会社に依頼すると費用・納期がかかり、個人店には負担が大きい
- SNSだけでは営業時間・メニュー・アクセスなどの基本情報が探しづらく、機会損失につながる

## 2. 企画概要

Liplは、**専門知識がなくても誰でも**、店舗情報・写真・メニューを入力するだけで、生成AIが公式ページ（LP）のキャッチコピー・説明文・レイアウトを自動生成し、即公開できるサービス。パソコンが苦手な店主でも、チャットに答えるだけで自分のお店のページが完成する。

```text
店舗情報入力
  ↓
AIヒアリング（チャット形式）
  ↓
公式ページ自動生成
  ↓
プレビュー・公開
```

## 3. ターゲットユーザー

- 個人経営の飲食店（カフェ・居酒屋・ラーメン店・レストラン・キッチンカー）
- Webサイト制作の知識・予算がない小規模事業者

## 4. 生成AIの活用ポイント

| 場面 | 生成AIの役割 |
|------|--------------|
| AIヒアリング | チャット形式で「お店のこだわり」「来てほしい客層」などをオープンクエスチョンで引き出す |
| LP自動生成 | ヒアリング結果と入力情報から、キャッチコピー・説明文・レイアウトを自動生成 |
| 多言語対応（上位プラン） | 日・英・中・韓へメニューや説明文を自動翻訳し、インバウンド需要に対応 |
| 再生成・調整 | 生成結果が気に入らない場合、AIとの対話で再生成・トーン調整が可能 |

使用モデル: Anthropic Claude（Haiku / Sonnet）

## 5. 独自性・差別化ポイント

- **専門知識ゼロ、誰でも使える** — ITの知識や経験がなくても、チャット形式の質問に答えるだけで完成する設計
- **入力から公開まで3分**という圧倒的な速さと手軽さ
- テンプレートへの当てはめではなく、AIヒアリングを通じて**店舗ごとの個性を言語化**してLPに反映する点
- QRコードを無料プランから提供し、印刷して店頭に貼るだけで来店客をオンラインへ誘導できる導線を用意
- 多言語自動翻訳により、個人店でも訪日外国人客への訴求が可能

## 6. 想定される効果・インパクト

- Web制作の知識・費用がなくても飲食店が自店の魅力を発信できるようになり、地域の個人店の販路拡大・売上向上に貢献
- QRコード・多言語対応により、観光客・インバウンド客の来店動線を強化
- 生成AIとの対話を通じて店主自身が「お店の強み」を再発見するきっかけになる

## 7. 今後の展望

- 本企画案をベースに詳細な企画提出を行う
- α版プロトタイプとして、店舗情報入力〜AIヒアリング〜LP生成〜プレビューまでのMVP機能を実装する
